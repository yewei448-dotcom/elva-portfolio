# 叶薇的个人网站

基于用户提供的《叶薇CV.pdf》制作的静态个人网站。包含个人介绍、四个可展开项目案例、工作经历、教育背景与联系方式，适配桌面和手机。原始 PDF 可通过页面下载。

## 本地预览

在此目录运行 `python3 -m http.server 4178 --directory dist`，然后打开 `http://127.0.0.1:4178`。

## 内容维护

- `dist/index.html`：页面内容及联系方式。
- `dist/styles.css`：布局、主题与响应式样式。
- `dist/script.js`：项目详情、项目筛选、手机导航和微信号复制。
- `dist/assets/yewei.jpg`：从原简历提取的个人照片。
- `dist/assets/yewei-cv.pdf`：用户提供的原始简历。
- `.openai/hosting.json`：Sites 私密站点的标识与部署目录。

网站使用浏览器原生功能，无构建步骤和第三方前端依赖。邮箱与电话使用 `mailto:`、`tel:`；页面不会自动发送消息。

原简历中 Insta360 结束月份未填写，网站仅展示开始月份。CMS 自动化的数据使用“120 分钟 → 25 分钟”，未采用原简历中与此不一致的“节省 95%以上”。项目流程图是基于描述制作的示意，并非系统截图。
